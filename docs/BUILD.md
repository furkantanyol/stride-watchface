# Stride: build, run, and sideload

## Prerequisites

1. Connect IQ SDK. Install the SDK Manager from the Garmin developer site, then install a recent SDK and the FR245 / FR245M device.
2. VS Code with the official Monkey C extension (publisher: Garmin).
3. A developer key. Generate one once:
   ```
   openssl genrsa -out developer_key.pem 4096
   openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem -out developer_key -nocrypt
   ```
   Point the Monkey C extension at `developer_key` in its settings. Never commit it (already in `.gitignore`).

## First-time project setup

This repo is hand-scaffolded, not generated by the VS Code wizard, so it has no `bin/` and no compiled key wired in. Open the folder in VS Code, set the developer key, and select a device when prompted. The app id in `manifest.xml` is a valid placeholder UUID; keep it for personal sideloading. Only generate a new one if you publish to the store.

## Build and run in the simulator

Use the command palette:

- "Monkey C: Build Current Project" produces `bin/Stride.prg`.
- "Monkey C: Run" launches the Connect IQ simulator with the face loaded.

In the simulator, set the device to Forerunner 245 Music. Use the simulator menus to set time of day, step count, and battery to exercise states.

## Sideload to the watch

1. Connect the FR245M over USB. It mounts as a drive.
2. Copy `bin/Stride.prg` to `GARMIN/Apps/` on the device.
3. Eject, then pick Stride from the watch face list on the watch.

For a shareable build, "Monkey C: Export Project" creates a `.iq` for the Connect IQ store.

## Test matrix (do not skip)

| State                         | What to check                                          |
|-------------------------------|--------------------------------------------------------|
| Morning, low steps            | arc nearly empty, pill shows "N to go" or streak       |
| Late day, near goal           | arc almost full, numbers legible                       |
| Goal reached                  | arc full, pill reads "10k done", today's bar over line |
| Fresh install, empty week     | past bars are flat stubs, looks intentional            |
| Week rollover (Sun to Mon)    | bars reset cleanly, week starts fresh                  |
| Streak across days            | increments, holds, resets after a missed day           |
| 12h and 24h clock             | hour formatting correct in both                        |
| Daylight / sunlight mode      | contrast holds                                         |
| Accent changed in settings    | all accent elements update on next render              |
| Low-power redraw              | once-per-minute update, no flicker, no seconds         |

## Memory check

After it builds, open the build output or device XML and confirm the watch-face memory use is comfortably under the FR245M budget. If it is close, the custom font (if added) goes first, then any string trimming.
